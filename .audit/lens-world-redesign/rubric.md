# Arena rubric (picker and cross-judge only)

Score each criterion 1–5 with one line of evidence (file and section in the candidate).

1. **Compounding without user effort.** Ordinary chat tasks and scheduled runs leave durable, cited Lens wiki and World changes that a later turn reads. Each "learns" claim names the observable record that proves it and the test that shows it. Writes stay gated: sourced vs agent-inferred are distinguishable, injected instructions cannot become memory, failed turns save nothing.
2. **Generality and onboarding.** Any asset class and non-market knowledge (science, technology, value chains) fit the World model. Ordinary users start from a preset with no ontology terms; power users shape the vocabulary through chat; changes are reversible and visible.
3. **Bot and research sessions.** The Bot is effortless and knows it is the Bot. Deep work moves to a session in one step with context, and what was learned comes back to the Bot. The separation is kept.
4. **Interface depth and subtraction.** Smallest public surface for the capability. One way to do each task. Obsolete paths deleted (no compatibility needed). No hand-synced lists, split ownership or pass-through layers.
5. **Verifiability, safety and cost.** Deterministic tests at real boundaries (broker, commit transaction, bridge mock, headless eval contracts). Authority model intact (Rust owns writes, permissions, as-of, shared wrapping). Background model calls bounded and never retried automatically.
6. **Feasibility.** A plan of small verifiable units that a few agents can land in about a day, with parallel units on disjoint files, and an honest "later" list.
