# Changelog

## Unreleased

- Introduce Loupist, a local-first financial research desktop app for macOS 13 or newer on Apple Silicon. Windows, Intel Macs and Linux are not supported in this release.
- Connect a supported model provider with an API key or account sign-in; no Loupist account or cloud sync is required.
- Read filings, market data and economic series through read-only connections, including OpenBB, OpenDART, KRX and Korea Investment.
- Keep each Loupist’s Chats, retained Sources, World, Lens, notes and private Journal in its own local folder, which can be copied and reopened.
- Build an evidence-linked World map from saved Sources, follow assets and import holdings as research context.
- Teach principles and develop reusable research methods in Lens, with editable pages, dated revision comparisons and evidence.
- Run numerical analysis in a pinned offline Python worker with no shell, network, process spawning or host environment.
- Read and edit research files in the selected workspace, and open files, citations, charts and documents beside Chat.
- Turn on Private chat to skip saved Memory reads and writes together while retaining Chat history.
- Run scheduled research and briefings while the app is running, with results in the Thread and run history in Scheduled tasks.
- Deliver signed and notarized Mac installers and consent-based signed updates, verifying that each update package names the version in its feed.
- Preserve compatible development data through backed-up upgrades and leave unsupported formats unchanged.
- License the app under AGPL-3.0-only; Loupist never trades, offers no trading execution, and is not a licensed adviser.
