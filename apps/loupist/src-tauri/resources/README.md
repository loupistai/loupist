# Generated runtime resources

`pi-runtime/`, `python-runtime/` and `embed_assets/` are generated by the
platform staging scripts before packaging. `pi-runtime/` contains the pinned Pi
runtime, workspace utilities and frozen OpenBB worker. `python-runtime/` contains
the pinned WASI Python snapshot and `loupist-python-worker`. `embed_assets/` holds
the pinned local embedding model that `stage-embed-assets.py` downloads and checks.
Do not commit or edit these trees as source. Model code runs in the Python worker,
not in a host shell.
