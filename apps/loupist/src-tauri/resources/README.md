# Generated runtime resources

`pi-runtime/` and `python-runtime/` are generated by the platform staging
scripts before packaging. `pi-runtime/` contains the pinned Pi runtime,
workspace utilities and frozen OpenBB worker. `python-runtime/` contains the
pinned WASI Python snapshot and `loupist-python-worker`. Do not commit or edit
either tree as source. Model code runs in that worker, not in a host shell.
