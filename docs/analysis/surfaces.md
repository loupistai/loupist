# Where results appear

Each calculated or fetched item has one surface. The host draws it; the model does not invent a second card.

## Where each item appears

| Item | Surface |
| --- | --- |
| Tool actions, Python runs, file reads/edits, errors and intermediate output | Compact steps in the originating reply while it runs, folded into a research summary when answer text appears. Open it to see the individual calls in order and inspect their results. Waiting approvals stay accessible alongside the summary. A stopped run marks open plan items Not done. A read refused for the answer's as-of date is marked skipped. Step labels follow the interface language. A step whose tool names an asset by `symbol`, `ticker` or `company` shows its asset page name when available |
| Calculated values, dataset inspection and chart-data queries | Under the step that produced them; a result citation opens that step. Computation results never open the side panel |
| Main answer, a few values, short tables and interpretation | Reply body. Numbered citations preview the title, kind, source, and a short excerpt |
| Numbers in the answer | A [checked number link](number-checks.md#number-checks) is the number itself with a dotted underline (wavy warning when a calculation differs). Its popover shows a calculation's title, formula (four lines, then Show all) and inputs with their sources or "Not linked to a source"; a passage with the number marked; up to four fields of the matched data row with provider, filing and retrieval dates; a price quote (value, currency, ticker, provider, retrieval time); or "From a step in this answer". A status line says when the number was not found, differs or was rounded, and an as-of answer adds "Known as of {date}". Show step expands the producing step inline and never opens the panel; Open in Evidence opens the retained copy with the passage or data cell marked. A price quote stays in that popover. Copy formula copies the formula with its inputs' sources. While the answer streams, number links have a faint underline and no popover; a link without a check stays a numbered citation |
| Published charts | A fixed-height card inside the answer (shorter in low windows): reserved with still hairlines and "Preparing" while the step runs, where the step started, filled in place with a fade, with Expand (wide windows), Copy data and Ask. An earlier answer draws the retained revision it published; if a later answer revised the chart, it keeps "Updated since this answer" with Open latest. A revision removed by retention shows as unavailable. Charts never open the side panel by themselves |
| Published documents | One outputs row, then the workspace reader |
| Workspace files the answer wrote successfully (file tools or `dataset_export`) and links | A "Files" chip row under the answer; a chip opens the file in the panel's Files reader, and its ⋯ menu's Show in Finder reveals it through `workspace_reveal` (saying so when the file has moved). Other working files stay in progress |
| Retrieved web pages | The actual website original opens first. The saved passage can be shown from that cited page after success, failure or a redirect ([Evidence and the browser](../ui/evidence-browser.md#chat-reading-column-and-in-app-browser)) |
| Equity price quotes | A saved quote basket, including `content[].text` that holds `results[]` with symbol, name, currency and last_price, opens a compact receipt in the answer. A number or grid cell uses only the check's pointer or the row's exact ticker, and does not match a symbol because its price equals the printed number. A batch citation lists the quotes that were saved, how many, and the technical original collapsed. Retrieval time is labelled separately from quote time, and quote time appears only when the row stored one. A truncated excerpt from a known quote tool stays this receipt. Articles, filings, files and other originals keep their readers |
| Data sources, local snapshots and web sources without a usable URL | Numbered citations and inline sources entries open the retained reader. The same URL or dataset is listed once |
| Search previews and Memory reads | Inline work progress. Explicit Memory citations still open the exact saved record |
| What the answer used and saved | One receipt line under a finished answer, in fixed order: sources read, names and relationships added to the Map, asset reads the answer moved ("{name}: {read}") or could not save, principles and methods used, items saved, proposals to review; "Nothing new saved" when the turn could save and saved nothing. Each segment opens its target (Evidence reader, the inline price-quote receipt, [mini map](../ui/map-lens.md#map-and-library), the asset page's thesis history, Lens entry, or the expandable change list with Undo, Review and Dismiss). Last, "{n} numbers to check" appears when a number was not found or differs; it scrolls to the first and pins its popover |
| What an as-of answer could not use | A note between the answer and its receipt ([as-of answers](point-in-time.md#composer-date-control)) |
The action of reading or creating an item belongs to progress; the item itself
may still open in a reader. Source-step links return to the originating
activity inline. The collapsed summary identifies issues so a reader can
locate a failed or interrupted step. Output previews are bounded, keyboard-scrollable,
selectable and copyable. File, chart, document, web and Memory readers remain restorable. System, tool and bundled method instructions describe this
same division and avoid publishing documents solely to expose raw tool output.
