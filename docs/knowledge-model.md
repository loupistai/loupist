# Knowledge and Memory

This page owns retained records, Map, retrieval, World processing and sharing. Host authority and
storage locations are in [Architecture](architecture.md).

## Map and Library

The Map is the observed World. Lens highlights recorded applications and does not draw a second graph. [Map and Lens](ui/map-lens.md#map-and-library).

## Working files and retained knowledge

Workspace files change immediately and are not Memory until a Source save commits. [Sources, notes and Journal](knowledge/sources-notes.md#working-files-and-retained-knowledge).

## Sources and exact references

A Source pins origin, coverage and bytes. A digest proves those bytes, not that they are true. [Sources, notes and Journal](knowledge/sources-notes.md#sources-and-exact-references).

## Worlds and graph processing

One sealed World per Loupist, published by the in-process extractor. [World processing](knowledge/worlds.md#worlds-and-graph-processing). Retrieval and defaults: [World search](knowledge/world-search.md).

### What you follow

Followed assets are an explicit list. [What you follow](knowledge/follow.md#what-you-follow).

## Memory permissions and retrieval

Read and save flags are per Chat. Reset removes only host-authored items the preview counted. [Memory](knowledge/memory.md#memory-permissions-and-retrieval).

### Memory under a cutoff

An as-of turn sees Memory as it stood then. [Memory](knowledge/memory.md#memory-under-a-cutoff).

## Working notes and Journal

Notes and Journal entries keep their own evidence inputs. [Sources, notes and Journal](knowledge/sources-notes.md#working-notes-and-journal).

## Asset pages

One page per instrument: the read, the thesis and the user's lines. [Asset pages](knowledge/asset-pages.md#asset-pages).

### Thesis and the read

The read is the Loupist's current claim about the instrument, with the reasons that support it. [Thesis and the read](knowledge/thesis.md#thesis-and-the-read).

### What changed

Host diffs since the last look. [What changed](knowledge/what-changed.md#what-changed).

### Results events

### Watchers

Kinds of checks and how an alert is stored. [Watchers](knowledge/watchers.md#watchers).

## Lens

Perspectives, principles and methods, and how a method is learned. [Lens learning](knowledge/lens.md#lens). The canvas control is [Map and Lens](ui/map-lens.md).

### Method learning

A background pass proposes methods from committed work. The user can pause or archive them. [Lens learning](knowledge/lens.md#method-learning).

### Using and correcting Memory in a Chat

A Chat can pin, correct or refuse a Memory item. The correction is staged until the reply commits. [Memory](knowledge/memory.md#using-and-correcting-memory-in-a-chat).

### User principles

Principles the user stated outrank a learned method when they conflict. [Lens learning](knowledge/lens.md#user-principles).
